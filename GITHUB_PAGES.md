# DF Pet Care static website

The public website is in `website/`. It is plain HTML, CSS and JavaScript and does not require WordPress or a database.

GitHub Actions validates the pages and publishes this directory to GitHub Pages after changes are pushed to `main`. The deployment can also be started from Actions → Publish DF Pet Care → Run workflow.

Repository Settings → Pages must use **GitHub Actions** as its publishing source.

To update content, edit the corresponding HTML page and push the changes with any required assets. Email and WhatsApp links launch the visitor's email or messaging application. This site does not process orders or payments.

Only public website materials belong in this repository. Company certificates, contracts, source business documents, local archives and the separate WordPress package are excluded from this publication.
